Rivestor is a marketplace on Solana where issuers list tokenized real-world assets and investors discover, buy and resell them in one place. It is built on **RTCS** (Rivestor Tokenized Controlling System), a set of Solana programs, legal templates and operating procedures that wrap every listed asset into a single token standard, the **rToken**.

<Info>
  **Status.** Rivestor is in private beta (MVP V1). The full RTCS release, including the fractional marketplace, is **Stage 2** and is in development. This documentation describes both what runs today and the target design, and labels each page accordingly. See [Status and roadmap](/status).
</Info>

## How an asset moves through Rivestor

<Steps>
  <Step title="List">
    An issuer or asset owner passes due diligence and either tokenizes an off-chain asset through the SPV Factory (Engine A) or deposits an existing token into an RTCS vault (Engine B).
  </Step>
  <Step title="Wrap">
    RTCS mints an rToken. Whitelists, KYC/AML attestations and geographic rules are enforced in code on every transfer.
  </Step>
  <Step title="Invest and trade">
    Eligible investors buy after a single KYC, receive distributions, trade on the secondary market or unwrap to the underlying asset.
  </Step>
</Steps>

## Design principles

| Principle | What it means |
| --- | --- |
| Non-custodial | Rivestor never holds user funds. Investors use self-custodial wallets, and originals sit in program-owned vaults that no one holds a key to. |
| Compliance in code | Eligibility, jurisdiction, lock-ups and holder limits are checked by the token itself on every transfer, not by policy alone. |
| One standard | Every asset, natively issued or wrapped, trades as an rToken with the same behavior, settlement path and disclosure surface. |
| Open market | Anyone can list and anyone eligible can invest. Rivestor aggregates supply rather than selling its own assets. |
| Legal isolation first | Each natively issued asset sits in a bankruptcy-remote vehicle with an independent Security Trustee. |
