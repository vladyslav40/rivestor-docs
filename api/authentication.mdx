---
title: "Authentication"
description: "Authorize API requests with an API key."
---

Send your API key as a bearer token in the `Authorization` header.

<CodeGroup>
```bash curl
curl https://api.rivestor.com/v1/accounts \
  -H "Authorization: Bearer $RIVESTOR_API_KEY"
```

```javascript Node.js
const response = await fetch("https://api.rivestor.com/v1/accounts", {
  headers: { Authorization: `Bearer ${process.env.RIVESTOR_API_KEY}` },
});
const data = await response.json();
```
</CodeGroup>

## Header

<ParamField header="Authorization" type="string" required>
  `Bearer <your API key>`
</ParamField>

<Warning>
  Keep your API key secret. Store it in an environment variable or secrets manager, never in client-side code or a public repository.
</Warning>

<Tip>
  If a key may be exposed, revoke it and create a new one immediately.
</Tip>
